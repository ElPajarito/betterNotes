## :material-book-open-variant: Reference wikis

The HackTricks-shaped sites — the ones to check before you start improvising.

| Site | Strongest on |
| --- | --- |
| [HackTricks](https://book.hacktricks.wiki/) | Breadth; the default first stop |
| [Exploit Notes](https://exploit-notes.hdks.org/) | Service-by-service exploitation notes, very fast to scan |
